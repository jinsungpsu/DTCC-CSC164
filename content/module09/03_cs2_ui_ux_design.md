# UI/UX

The concept of UI/UX focuses on layout, appearance, functionality, and design.

---

# What is UX?

“User experience encompasses all aspects of the end-user’s interaction with the company, its services, and its products.”

– Don Norman

---

# What is UI?

A user interface is the point of interaction between the user and a digital device or product.

---

# UI vs UX

- UX is about the overall feel of the experience.
- UI is about how interfaces look and function.

---

# What is Good UI?

- Clarity & Simplicity
- Consistency
- Responsiveness
- Visual Hierarchy
- Accessibility

---

# What is Good UX?

- User-Centered Design
- Efficiency
- Feedback & Interaction
- Error Prevention & Recovery
- Satisfaction

---

# From Principle to Design Choice

For a course registration form:

| Principle | Concrete choice |
| --- | --- |
| Clarity | Label the action "Register for course" |
| Consistency | Use the same label for the same action |
| Feedback | Confirm success or explain the failure |
| Error recovery | Keep entered values when validation fails |
| Accessibility | Provide meaningful labels and keyboard access |

Explain how each choice helps a person complete a task.

---

# Check More Than Appearance

- Can you reach controls in a sensible order using the keyboard?
- Can you tell which control currently has focus?
- Do labels explain what belongs in each field?
- Are errors explained with text rather than color alone?
- Does the interface remain usable when resized?

Try these checks on your JavaFX interface.

# What is a wireframe?

A two-dimensional skeletal outline of a webpage or app.

---

# Purpose of wireframe

- Keep concepts user-focused.
- Clarify and define features.
- Quick and inexpensive to create.

---

# Plan a Small JavaFX Interface

Task: Let a student enter a name and see a welcome message.

```text
Student name: [                    ]
              [ Show welcome ]

Message: Welcome, ...
```

- Choose a Label, TextField, Button, and a result display
- Reserve space for feedback and errors
- Decide what should happen when the name is blank
- Map the sketch to containers and controls

Button behavior will be covered with event handlers.

# Summary

- UI concerns the interface a person sees and interacts with
- UX concerns the broader experience of using a product or service
- Clear, consistent, accessible interfaces support effective interaction
- Feedback and error recovery help people complete tasks
- Wireframes make layouts and features easier to discuss before implementation
- Observe task completion and revise based on specific difficulties
