# Arrays of Objects

Definition: An array of objects is a collection of references to objects of a specific class.

- Purpose: Allows you to store multiple objects of the same type in a single array.
- Unlike arrays of primitives, an array of objects stores references to the objects.

---

# Declaring an Array of Objects

```java
Car[] cars = new Car[5];
// Array of 5 Car Reference Variables! (currently null)
```

The array size is defined, but the objects themselves must be instantiated separately.

---

# Instantiating Objects in an Array

- Declare the array (of reference variables).
- Instantiate each object in the array.

---

# Array of Objects Example

```java
Car[] cars = new Car[3];
cars[0] = new Car("Ford");
cars[1] = new Car("BMW");
cars[2] = new Car("Audi");
```

---

# Initializing an Array of Objects Example

```java
Car[] cars = {
    new Car("Tesla"),
    new Car("BMW"),
    new Car("Audi")
};
```

---

# Passing Arrays of Objects to Methods

```java
printCarModels(cars);
```

# Instance Variables

- Belongs to an instance of a class.
- Each object has its own copy.
- Declared inside a class but outside methods.

---

# Instance Variable Key Concepts

- Each object has its own copy of instance variables.
- Initialized when an object is created.
- Store object-specific data.

---

# Instance Methods

- Same concept but with methods.
- Code related to a specific object.

---

# Static Variables

Definition: A static variable is shared across all instances of a class.

---

# Why Use Static?

- Shared State
- Memory Efficiency
- Global Access

---

# Static Methods

Definition: A static method belongs to the class, not instances of the class.

---

# Static vs Instance Variables

| Feature | Static Variables | Instance Variables |
|---|---|---|
| Belongs to | Class | Object |
| Access | Class name | Object reference |
| Lifetime | While class loaded | While object exists |

---

# Static vs Instance Methods

| Feature | Static Methods | Instance Methods |
|---|---|---|
| Belongs to | Class | Object |
| Call | Class name | Object reference |

---

# Using this to Call Instance Methods

```java
this.accelerate();
```

---

# This in Static Contexts

- Cannot be used in static methods.
- Static methods do not belong to any specific instance.

---

# Constructor Chaining

# Passing Objects as Parameters

- Methods can operate on references to objects.
- Enables modification of object state.

---

# What Happens Behind the Scenes

- Reference Passing
- No New Object

# Benefits of Passing Objects as Parameters

- Efficiency
- Flexibility
- Encapsulation
